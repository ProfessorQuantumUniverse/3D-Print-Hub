Eine moderne Website rund um meinen 3D-Druck-Service: stöbere durch gedruckte Modelle, informiere dich über verfügbare Materialien und buche einen Druck direkt online.

## ✨ Features

- 🖼️ **Galerie** fertiger 3D-Drucke
- 🧱 **Materialübersicht** mit Eigenschaften
- 📅 **Online-Buchung** für Druckaufträge
- 📊 **Status-Seite** für laufende Drucke
- 📱 Voll **responsive** Design

## 🛠️ Tech-Stack

`HTML5` · `CSS3` · `JavaScript` · `GitHub Pages`
